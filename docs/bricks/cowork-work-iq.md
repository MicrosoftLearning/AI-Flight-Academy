# Ground Cowork in your work (Work IQ)

**Tool:** Cowork + Work IQ

<!-- #region guide -->
Cowork can already see your real Microsoft 365 work through **[Work IQ](/bricks/work-iq)** - mail, sent mail, calendar, Teams, files, org chart - with nothing to connect. Most scenarios ask you to turn some of that into a reusable profile: a persona, an audience card, a set of rules.

## Steps

1. In a **new Cowork task**, ask Work IQ to draft the profile from your own signals. For example:

   ```text
   Build an audience card about me from Work IQ - who I write for, what they need, and how they decide.
   ```

   or

   ```text
   From my sent mail and calendar, draft a short profile of how I work and what I care about.
   ```

2. Read what comes back as a **first draft, not the truth.** Work IQ sees what you *did*, not always *why*.
3. Correct it in the chat - add the rule it missed, fix the read it got wrong.
4. Save it into the file the skill uses (the build page names it).

**You'll know it worked when...** the profile reads like you - or like the audience you serve - to someone who knows the real thing.

::: warning Keep private data private
Work IQ only ever shows you what you can already see. Keep it on your own screen - don't paste real work into a shared doc, a demo, or a screenshot.
:::

## Apply it to your scenario

Scenario 1 turns this into a persona of *you*; Scenario 2 turns it into an audience *you write for*. Same move: let Work IQ draft from real signal, then correct it.
