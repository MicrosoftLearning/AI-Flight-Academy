# Which altitude is right for me?

::: tip Pick the tool you'll actually keep using
There's no prize for picking the hardest altitude, and no reason to reach for Scout or Code just because they sound more advanced. The goal is to get better with a surface you'll use day to day - so pick the one you can see yourself coming back to after the session, and build there. Cowork, Scout, and Code all get you to something that works.
:::

## Not sure?

- **Never built an agent before, or don't want any setup?** 🟢 **Cowork**. Point and go - nothing to install.
- **Happy to do a little setup for something more capable?** 🔵 **Scout**. Needs M365 and a GitHub account.
- **Comfortable in VS Code, or up for vibe coding?** 🟣 **Code**.
