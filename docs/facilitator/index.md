# Facilitator Guide

Use these pages to run Scenario 1 in the room.

- [Role cards](/facilitator/role-cards) — printable roles for Cowork teams and Code council teams.
- [Interview script](/facilitator/interview-script) — behavioral questions, and the dilemma set used by the Code track's scripted test.
- [Coach playbook](/facilitator/coach-playbook) — common failure modes and how to unstick teams.

## What to prep

- [ ] Confirm the room can access Cowork, VS Code Copilot, and the GitHub Copilot CLI.
- [ ] Share the Twin Forge Cowork skill download location.
- [ ] Share the Avery Washington persona pack location for anyone not using their own data.
- [ ] Print the role cards.
- [ ] Prepare the mid-build constraint: senior stakeholder ask versus peer promise.
- [ ] Remind everyone to have a real unresolved thread in mind — a request they haven't answered. The twin retrieves it; nothing needs pasting.
- [ ] Remind coaches: no scoring, no leaderboard, no personal data on shared screens.

::: tip The facilitator job
Keep teams moving. `soul.md` by 0:35, a working twin by 0:50, and their own third file started by 1:10. Protect that last block — it's where the transferable skill lands.
:::
