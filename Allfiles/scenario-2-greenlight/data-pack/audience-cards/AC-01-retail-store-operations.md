# AUDIENCE CARD · AC-01
## 🛒 Store Operations Lead — Contoso Retail

> **In one line:** Runs the floor at a 40-person store. Not in IT, doesn't write code, has eight minutes.

---

## The business

| | |
|---|---|
| **Business unit** | Contoso Retail — 1,200 stores, 62,000 employees, thin margins |
| **Their store** | ~$12M annual revenue, 40 associates, 4 shift supervisors |
| **Measured on** | Labor hours vs. plan · shrink · associate turnover · customer sat |
| **Reports to** | District Manager → Regional Ops |
| **Career path** | Promoted from shift supervisor. Retail their whole career. No IT background. |

## Where they work

| | |
|---|---|
| **Physically** | On the floor. Standing. |
| **Devices** | A shared back-office desktop (Windows) and a company iPhone. **No personal laptop.** |
| **When they read** | Between open and the first rush, or after close when they're tired |

## What they know

| | |
|---|---|
| ✅ **Fluent — assume it, don't explain it** | The shift scheduling system · inventory counts · shrink reports · the weekly ops cadence · Teams and Outlook · escalation paths |
| 🟡 **Shaky — seen it, couldn't do it unaided** | Excel beyond sort and filter *(pivot tables: no)* · any settings panel more than one level deep |
| ❌ **Never seen it — content assuming this has failed** | Command line, terminal, PowerShell · APIs, JSON, webhooks, connectors, environments, tenants · admin centers of any kind |
| 🚫 **Words that stop them reading** | deploy · instance · provision · schema · endpoint · tenant |

## What they're trying to do

| | |
|---|---|
| **Stated goal** | *"Use Copilot so I stop losing my Sunday nights to the schedule."* |
| **The real job** | Every minute Copilot saves is a minute back on the floor with the team — which is where all four of their metrics actually move |
| **Do not care about** | What Copilot is · how it works · which model it uses · what's coming next quarter |

## How they learn

| | |
|---|---|
| **Learns by** | Being shown once, then doing it themselves |
| **Will actually finish** | A 60-second video · a single-page job aid · a three-step card |
| **Will not finish** | 800 words of anything. They will read the first two lines and decide. |
| **Time budget for learning** | 5–10 minutes, once. There is no session two. |
| **Passes it on by** | Standing next to a supervisor and doing it with them — not by forwarding a link |
| ⭐ **Best format** | Short video, or one page pinned in the back room |
| ⚠️ **Worst format** | A long document. Anything that assumes they're sitting down. |

> **The format question for this reader:** if the answer is a page of prose, the answer is probably wrong.

## Constraints

| | |
|---|---|
| ⏱️ **Time** | 5–10 minutes, standing, interrupted at least twice |
| 📱 **Screen** | Phone more often than desktop |
| ✋ **Approval** | Anything touching labor cost, or inventory over $500, goes to the DM |
| 🗣️ **Language** | English is their second language. They read it fluently. **Idioms and wordplay slow them down.** |
| 🔁 **Pass-it-on** | They re-teach almost everything to their supervisors. **Content they can't re-explain in their own words dies with them.** |
