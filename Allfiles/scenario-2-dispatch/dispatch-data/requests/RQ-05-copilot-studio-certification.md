# REQUEST · RQ-05
## We need a certification for Copilot Studio agent builders

**Requester:** Ravi K., a Strategic Partnerships lead
**Came in via:** intake form
**Date:** two weeks ago

---

## The ask

> "Partners keep asking how they prove someone can *build* agents in Copilot Studio. There's no credential for it. We want a real, recognized certification - something with weight, that a hiring manager would trust."

## Context

Demand for a defensible credential is real. But Copilot Studio ships fast - the product surface changes often, which is a problem for a stable, assessable exam.

## What we know

| Field | Value |
|---|---|
| Stated audience | Partner practitioners / agent builders (and their hiring managers) |
| Topic | Building agents in Copilot Studio |
| Desired outcome | A recognized, defensible certification |
| Deadline | None stated - "we want it right," not fast |
| Trigger / motion | Partner demand, hiring-signal gap |

## Notes

- "Recognized certification" points straight at credentialing - but "product changes often" pulls against stable, certifiable objectives.
- Someone has to *prepare* builders for the cert, which is a different job from *owning* the cert.
